# XMage Community Patch RC1.1 CORE — 1.4.61

## English

### What is included

- XMage client and server 1.4.61.
- Official XMage Launcher 0.3.8.
- Bundled Java Runtime Environment 8u201.
- Community Patch configuration and tools.
- Deck downloader and approximately 600 prepared decks.
- 4K UI scaling configuration.
- HD card images are **not** included. Download them from the official XMage launcher after installation.

### Installation

1. Download `XMage-RC1.1-CORE-v-1.zip` from the [RC1.1 CORE release](https://github.com/vros01-Kabutosan/XMage-Community-Patch/releases/tag/RC1.1-CORE-v-1).
2. Extract the ZIP to a dedicated folder. Do not merge it with Forge, Cockatrice, or another XMage installation.
3. Start `XMageLauncher-0.3.8.jar`.
4. Use the bundled Java 8u201 runtime when prompted or when configuring a shortcut.
5. From the launcher, download the card editions/images you need.
6. Start the local server and connect the client to `localhost:17171`.

### Verification

- ZIP integrity: verified with 7-Zip.
- Files: 5,067.
- SHA-256: `DAF53A97BC105D88353105B63F46D9965283E7A8C6DB67B8A817C1E17D996EE7`.
- Java runtime: 8u201.
- Recommended client memory: 4 GB or more.

### Important

This is an unofficial community package and is not affiliated with the official XMage developers. Keep user data and backups separate from replaceable program files.
