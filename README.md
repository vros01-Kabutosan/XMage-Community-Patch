# XMage Community Patch for 1.4.60V3

Community-maintained patch and tooling package for **XMage 1.4.60V3**, focused on Windows compatibility, card/deck fixes, validation, deck workflows and a smoother day-to-day XMage experience.

> [!IMPORTANT]
> This project is **not an official XMage release** and is **not affiliated with or endorsed by the official XMage maintainers**. It is an independent community patch built on top of XMage.

## Installation

1. Back up your current XMage installation if you want to preserve it.
2. Download the package that matches your use case. `Complete Windows` is recommended for most users.
3. Extract the ZIP to a folder with write permissions.
4. Follow the bilingual instructions included with the package.
5. Start XMage using the included/standard XMage launcher configuration.

This patch replaces or updates XMage program components because several fixes cannot be applied through configuration files alone.

## Java / RAM recommendation

For better stability with large card databases, images and long sessions, allocating **4 GB of RAM** to XMage is highly recommended.

Use:

```text
-Xmx4G
```

Use only **one** `-Xmx` parameter in the Java options.

XMage itself is a Java application. The upstream XMage project documents Java 8 or later for the launcher; this community RC1 is primarily tested around the Windows/Java setup used for this build.

## Deck downloader dependencies

Some deck tools may automatically install standard Python dependencies when they are missing, including:

- `selenium`
- `undetected-chromedriver`
- supporting Python libraries

These are used to access supported deck sources, handle dynamic web pages, download deck lists and validate card information. Scripts may execute `pip` automatically when a required dependency is missing.

**No hidden or unrelated software is intentionally installed by this project.**

Online functions may connect to compatible services such as **MTGGoldfish, MTGTop8 and Scryfall**.
